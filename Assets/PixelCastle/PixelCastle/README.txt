PIXEL CASTLE - Unity asset paketi
=================================
Kurulum: "PixelCastle" klasörünü Unity projende Assets/ içine sürükle.
Editor/PixelCastleImporter.cs tüm PNG'leri otomatik ayarlar:
  Sprite (Single), Pixels Per Unit = 84, Filter = Point, Compression = None, Pivot = Bottom Center

Sprites/ (her biri şeffaf arka planlı ayrı PNG)
  Duvarlar : wall_straight_long, wall_straight_short, wall_vertical, wall_segment_short,
             wall_crenellated, wall_section_low, wall_broken, wall_merlon_block,
             wall_rubble_small, wall_end_broken, wall_end_square, wall_end_round
  Köşeler  : corner_outer_left, corner_outer_right, corner_wall_bracket
  Kuleler  : tower_small_open, tower_small_closed, tower_tall_open, tower_tall_closed
  Kapılar  : gatehouse_doors, gate_barricade
  Diğer    : ladder, ladder_small, rampart_scaffolding
  Karolar  : tile_stone, tile_stone_cracked, tile_stone_brick, tile_wood

castle_spritesheet.png : yazılar silinmiş, şeffaf tam sayfa (Sprite Editor'da
                         "Automatic" slice ile tek dosyadan kullanmak istersen).
